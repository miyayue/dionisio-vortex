# Projeto Dionísio
Esse projeto de IoT é o desafio de treinamento do laboratório de formação e inovação Vortex. O desafio consiste em construir uma mini adega de vinho inteligente, em que o usuário possa monitorar a temperatura e umidade dentro da adega e com controle de acesso por RFID ou controle remoto através de um Dashboard.

# Instruções
## Firmware
No VSCode, instale a extensão `PlatformIO`. Modifique os valores das variáveis `ssid` e `pswd` para o nome de sua rede WiFi e senha, respectivamente. Salve o arquivo e rode o comando `Upload and Monitor` para enviar o programa ao Esp32. 

## Dashboard
O dashboard pode ser visualizado em https://io.adafruit.com/letholanda/dashboards/dionisio-dashboard.
